2. Feature Engineering¶

The same eight features as Task 1, built only from information available at the close of today (day t):

  • return_1d - today's percentage price change (momentum).
  • volatility_10d - rolling standard deviation of the last 10 daily returns (recent turbulence).
  • dist_sma21, dist_sma63, dist_sma252 - percentage distance of today's close from its 21-, 63- and 252-day moving averages (short/medium/long-term trend position).
  • rsi, tsi, tsi_signal - the Relative Strength Index and True Strength Index oscillators.

The target here differs from Task 1: instead of the exact return, target_direction is binary (1 = closes higher tomorrow, 0 = it doesn't). This is an easier problem than Task 1's regression - only the sign matters, not the size - worth trying separately given Task 1 found almost no linear signal.

In [4]:
df = orcl_1d_data.copy()

df['return_1d'] = df['close'].pct_change()
df['volatility_10d'] = df['return_1d'].rolling(10).std()
df['dist_sma21'] = (df['close'] - df['SMA_21_Close']) / df['SMA_21_Close']
df['dist_sma63'] = (df['close'] - df['SMA_63_Close']) / df['SMA_63_Close']
df['dist_sma252'] = (df['close'] - df['SMA_252_Close']) / df['SMA_252_Close']
df['rsi'] = df['RSI_25_Close']
df['tsi'] = df['TSI_25_13_13']
df['tsi_signal'] = df['TSI_Signal_13']

# Target: did price close higher the next day? (binary classification)
df['next_return'] = df['close'].shift(-1) / df['close'] - 1
df['target_direction'] = (df['next_return'] > 0).astype(int)

feature_cols = ['return_1d', 'volatility_10d', 'dist_sma21', 'dist_sma63', 'dist_sma252', 'rsi', 'tsi', 'tsi_signal']

4. Train/Test Split and Feature Scaling¶

Chronological split, same reasoning as Task 1. KNN is distance-based, so features need scaling first - otherwise dist_sma252 (~+/-0.3) would be swamped by rsi (0-100) purely by scale, not relevance. StandardScaler fixes that, fit only on training data so no test-period information leaks in.

6. Algorithm: K-Nearest Neighbors (KNN)¶

KNN classifies a new day by finding its k most similar historical days - Euclidean distance across the 8 scaled features - and taking a majority vote of their outcomes (Cover and Hart, 1967). There is no training phase; the "model" is just the stored data. k=15 means each prediction votes among the 15 nearest days: a smaller k is more sensitive to individual points (higher variance), a larger k smooths toward the overall class balance (higher bias) (James et al., 2023).

In [11]:

knn_model.fit(X_train_scaled, y_train)
knn_pred = knn_model.predict(X_test_scaled)

9. Cross-Validated Performance (More Robust Than a Single Split)¶

Same idea as Task 1: one split is noisy. TimeSeriesSplit runs 5 chronological folds, averaging accuracy and balanced accuracy. The scaler is refit inside each fold on that fold's training data only, so no fold leaks into another.

In [15]:
from sklearn.model_selection import TimeSeriesSplit

X_all = df[feature_cols]
y_all = df['target_direction']

tscv = TimeSeriesSplit(n_splits=5)
cv_acc, cv_bal_acc = [], []

for train_idx, test_idx in tscv.split(X_all):
    X_tr, X_te = X_all.iloc[train_idx], X_all.iloc[test_idx]
    y_tr, y_te = y_all.iloc[train_idx], y_all.iloc[test_idx]

    fold_scaler = StandardScaler()
    X_tr_scaled = fold_scaler.fit_transform(X_tr)
    X_te_scaled = fold_scaler.transform(X_te)

    fold_knn = KNeighborsClassifier(n_neighbors=15).fit(X_tr_scaled, y_tr)
    pred = fold_knn.predict(X_te_scaled)
    cv_acc.append(accuracy_score(y_te, pred))
    cv_bal_acc.append(balanced_accuracy_score(y_te, pred))

print('5-fold TimeSeriesSplit cross-validation for KNN:')
print(f'Mean CV Accuracy:          {np.mean(cv_acc):.4f} (std {np.std(cv_acc):.4f})')
print(f'Mean CV Balanced Accuracy: {np.mean(cv_bal_acc):.4f} (std {np.std(cv_bal_acc):.4f})')

Summary¶

On the test set, KNN scores Accuracy = 0.4947, Balanced Accuracy = 0.4959, F1 (macro) = 0.4947, ROC-AUC = 0.4960, MCC = -0.0083 - a negative MCC means it is marginally worse than random guessing. Section 3's heatmap and Section 3.1's boxplots show none of the eight features separate Up/Down meaningfully, and Section 8's TSI plot shows two of KNN's eight distance coordinates are themselves 0.91 correlated - fewer independent dimensions than it looks. Full comparison against the SVM (2584023_Task2_Algo2.ipynb), references, and improvement suggestions are in the written report.
