# NQ1 Poster: ready-made Tableau workbook

| File | What it is |
|---|---|
| `NQ1_Poster.twbx` | **Open this one.** A packaged workbook: six sheets (V1–V6) with the data inside |
| `NQ1_Poster.twb` + `Data/` | The same workbook unpackaged (backup if the `.twbx` gives trouble) |
| `Data/V1_price.csv` … `V6_regime.csv` | One tidy table per chart, built from the notebook outputs |

The workbook was generated by `../build_tableau_workbook.py` and checks out against Tableau's
published 2026.1 workbook schema. Tableau draws every chart itself.

## 1. Open it (Windows)

1. Copy the whole `Tableau_Workbook` folder to your Windows computer (USB stick, OneDrive or email).
2. Double-click **`NQ1_Poster.twbx`**, or open Tableau Desktop → File → Open.
3. **If Tableau says a data source cannot be found:** click **Edit Connection** (or "Locate file") and browse to the matching CSV in `Data/`. Repeat for each file it asks about, then **File → Save As → Tableau Packaged Workbook (.twbx)**.
4. **If the `.twbx` will not open at all:** open `NQ1_Poster.twb` instead, with the `Data` folder beside it.

You should see six sheet tabs: **V1 Price trend, V2 Drawdown, V3 Annual returns, V4 Volatility, V5 Fat tails, V6 Regime scorecard**. Each already has its title, fields, mark type and colours.

## 2. Finishing touches (about 30–45 minutes)

These settings are quicker to do by hand than in generated XML, and doing them is also good evidence of your own Tableau work.

| Sheet | Do this |
|---|---|
| **All** | Right-click each axis → **Edit Axis** → set a clear title (e.g. "Drawdown (%)"). Format → Workbook → choose one font. |
| **V1** | Right-click the y-axis → Edit Axis → tick **Logarithmic**; title "Futures price, index points (log scale)". Right-click points → **Annotate → Point**: Mar 2000 peak, Oct 2002 trough (−83%), Nov 2008 low, Oct 2026 all-time high. |
| **V2** | Edit Axis → Fixed range −100 to 0. Annotate: Dot-com −83% (regained Aug 2016), GFC −54%, COVID −28%, 2022 −35%, 2025 −23%. |
| **V3** | Analytics pane → drag **Reference Line** onto the chart → Table → Median of Annual Return Pct (about 17). Optional: drag **Year Type** to Opacity or Detail, and annotate 1999 "partial" and 2026 "YTD". Show labels on 2003, 2008, 2022 and 2023 (right-click → Mark Label → Always Show). |
| **V4** | The median and 90th-percentile lines are already drawn as grey and orange series. Annotate the peaks: 2000–02 99%, 2008 95%, 2020 90%, 2025 58%. |
| **V5** | Right-click the y-axis → Edit Axis → **Logarithmic**, fixed start 0.8. *Optional, nicer:* change the mark type to **Bar** and split the two series onto a synchronised dual axis (bars for Observed, line for Normal), as in the reference chart. Add a caption: "117 days beyond ±3 s.d. vs 19 expected; 47 beyond ±4 s.d. vs 0.4". |
| **V6** | Right-click the y-axis → untick **Show Header**. Add the caption: "Volatility gap significant (p < 0.001); return gap not significant (p = 0.22)". |

Compare each sheet with the reference images in `../poster_visuals/`.

## 3. Interactive dashboard (Week 7)

1. New Dashboard → Size: Fixed, 1400 × 1000.
2. Drag **V1** to the top and **V4** below it.
3. V1's dropdown → Filters → Date. On the filter card's dropdown → **Apply to Worksheets → Selected Worksheets** → tick V4. Because V1 and V4 use different data sources, use **Data → Edit Blend Relationships** (link on Date) if the option is greyed out.

## 4. Export for the poster

For each chart: New Dashboard → Fixed size **2000 × 1000** → drag in the sheet (Fit: Entire View) → increase the fonts (title about 20 pt, axes about 14 pt) → **Dashboard → Export Image** → PNG. In `NQ1_Research_Poster.pptx`, right-click each chart → **Change Picture → From a File**.

## 5. Save your evidence

**File → Save As → Tableau Packaged Workbook** (`NQ1_Poster_SantiagoCruz.twbx`) and keep it with your drafts.
