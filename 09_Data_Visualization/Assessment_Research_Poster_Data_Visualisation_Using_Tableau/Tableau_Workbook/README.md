| File | What it is |
|---|---|
| `NQ1_Poster.twb` + `Data/` | **Open this one.** Six sheets (V1–V6) styled to match the notebook's v2 charts (`../poster_visuals_v2/`) |

## Check each sheet (5 minutes)

Compare each sheet with the matching picture in `../poster_visuals_v2/`. If something differs, use these one-click fixes:

| If you see… | Do this |
|---|---|
| V5 shows two separate charts | Right-click the second pill on Rows → **Dual Axis**, then right-click the right axis → **Synchronize Axis** → untick **Show Header** |
| V5 bars look like a line, or the line looks like bars | On the Marks card, click each measure's tab and choose **Bar** (Observed) or **Line** (Normal) |
| A label is missing because it overlaps another | Right-click the mark → **Mark Label → Always Show** |
| A label sits on top of a line | Drag it to a clearer spot |
| A reference line is solid instead of dashed | Right-click it → **Format** → Line → choose a dashed pattern |
| A line is shorter at the start (V1 average, V4 volatility) | Expected: those measures need 252 and 21 days of history first |
| V1 or V2 shows only about 28 points | Click the **Date** pill → **Exact Date**, then **Continuous** |

Optional extras:
- **Annotate Point** boxes like the notebook's: right-click a mark → **Annotate → Point**.
- The light-orange shading above the V4 stress line: drag a **Reference Band** from the Analytics pane, from the stress line to the axis maximum.

## Interactive dashboard (Week 7)

1. New Dashboard → Size: Fixed, 1400 × 1000.
2. Drag **V1** to the top and **V4** below it.
3. V1's drop-down → Filters → Date. On the filter card's drop-down → **Apply to Worksheets → Selected Worksheets** → tick V4. Because V1 and V4 use different data sources, use **Data → Edit Blend Relationships** (link on Date) if the option is greyed out.

## Export for the poster

For each chart:
1. New Dashboard → Fixed size **2000 × 1000** → drag in the sheet (Fit: Entire View).
2. Increase the fonts: title about 20 pt, axes about 14 pt.
3. **Dashboard → Export Image** → PNG.
4. Save the PNGs into a new folder, `../tableau_exports/`, using the same file names as in `../poster_visuals_v2/`.
5. In the poster, right-click each chart → **Change Picture → From a File**.
